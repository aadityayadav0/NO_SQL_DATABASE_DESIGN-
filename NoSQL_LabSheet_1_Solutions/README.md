# NoSQL LabSheet 1 — MongoDB Solutions
BCA V Semester / III Year, Session 2026–2027.

Based on the supplied Lab Sheet-01 PDF. Includes answers for all 25 questions, MongoDB Shell scripts for Q1–Q21, Compass instructions for Q22–Q23, SQL comparison for Q24, and a report template for Q25.

## Run
Install/start MongoDB Community Edition and install `mongosh`. From this folder run:
`mongosh`
then:
`load("mongosh/lab01_all_practicals.js")`

WARNING: The script drops the Departments collection and drops StudentDB for Q19–Q20 before recreating it for Q21. Run only against disposable lab data. Outputs are illustrative descriptions, not claimed live execution logs. Capture your own Compass/Shell screenshots.
